# Pelmen Visuals

Fabric mod for Minecraft 1.21.11 with HUD, GUI and visual features.

## Features

- **HUD Display**: Shows coordinates, FPS, health and armor
- **GUI Manager**: Toggle-able GUI panel with RIGHT_SHIFT
- **Night Vision**: Toggle-able night vision effect with N key
- **Visual Manager**: Base rendering system for future features

## Keybindings

- **N** - Toggle Night Vision
- **RIGHT_SHIFT** - Toggle GUI Panel

## Installation

1. Install Fabric Loader for Minecraft 1.21.11
2. Place the mod jar in your `mods` folder
3. Launch Minecraft with Fabric profile
